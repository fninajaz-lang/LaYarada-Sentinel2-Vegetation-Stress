# Sentinel-2 NDVI NDMI Analysis — La Yarada Los Palos

This repository contains Google Earth Engine scripts used to analyze vegetation dynamics and water stress in the La Yarada-Los Palos coastal aquifer (Tacna, Peru) using Sentinel-2 imagery.

## Data

Sentinel-2 imagery (Copernicus Programme)

Google Earth Engine platform

## Methods

- NDVI computation
- NDMI computation
- Vegetation stress index
- Temporal trend analysis
- Pearson correlation
- Annual aggregation
